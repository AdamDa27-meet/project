# Color game
- Color game is a simple game where you select from a list of colours from a dropdown menu and leave a comment or suggestion for each page/colour. There are three hidden easter eggs which I will mention further on.

# Features
- At the top is the title of the game, Color Game
- Under it is a dropdown menu where users choose from different colours for the background, including red, blue, green, purple, and more.
- Under that is the comment section, where users can leave a comment and then view their most recent comment under it, as the app displays it.
- The three easter eggs are:
    - Typing 'rainbow' in the comment section
    - Typing 'hello' in the comment section
    - Typing 'green' in the comment box
